Le Concept

Création d'un site web explorant l'impact de la loi 96 sur les détaillants de jeux de société au Québec. L'objectif était de proposer une interface claire tout en gérant une structure de données complexe pour le catalogue.

Défis Techniques

Le développement a nécessité la création de blocs Gutenberg sur mesure et l'intégration de champs avancés via ACF (Advanced Custom Fields) pour structurer le contenu de manière dynamique. Le thème enfant WordPress a été entièrement stylisé en CSS personnalisé.

[Capture détail 2]

Résultat

Une plateforme administrable facilement, où les champs personnalisés permettent de maintenir le catalogue à jour sans toucher au code, répondant ainsi parfaitement aux besoins du projet.
